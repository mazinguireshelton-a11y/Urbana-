Urbana - Social Infrastructure Calculator
Developed by: Shelton Manuel (via Termux/Mobile)
📌 Project Overview
Urbana is a logic-based tool designed to automate the calculation of essential resources for human settlements in Mozambique. The project aims to translate population data into accurate estimates of basic needs, helping to plan more resilient and organized communities.
⚙️ Features & Logic
Water Consumption: Estimates daily water needs based on international sanitation standards and population density.
Energy Sizing: Calculates the basic load required for public lighting and essential domestic services.
Resource Projection: Estimates the initial materials and inputs needed for basic infrastructure setup.
📱 Technical Challenge (Mobile-First Development)
This project was developed entirely on a mobile device using Termux as the primary development environment. Due to the lack of a physical computer, I utilized AI tools to assist with syntax optimization and debugging. However, the engineering logic, variables, and social parameters were entirely structured by me based on the local Mozambican context.
